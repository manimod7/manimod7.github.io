Cricket · data and ML

Chase

Chase estimates each team's chance of winning a T20 match and updates it after every ball, so you can watch a game swing in real time.

What you can do

  • Replay any recorded IPL match ball by ball and watch the win probability move.
  • What if: set the innings, score, wickets, balls left and target to see the probability for any situation.
  • Model quality: see how well the probabilities match real outcomes, next to simple baselines.

How it works

  • Data: ball-by-ball records of complete 20-over IPL matches from Cricsheet, with team names unified across franchise renames.
  • Model: LightGBM gradient boosting with monotone constraints so it follows cricket logic, then probability calibration. Train, validation and test sets are split by date (80/10/10) so the model never sees the future.
  • Same maths everywhere: the trained trees are exported to JSON and evaluated identically in the browser, in Python and in LightGBM, with parity tests.
  • Backend: a FastAPI service, deployable on AWS Lambda, for live scoring. The hosted demo runs entirely in your browser.

Results on 119 held-out matches

0.191Brier score, calibrated model
0.050expected calibration error
0monotonicity violations

The model scores level with a plain logistic-regression baseline (Brier 0.190), and the app says so. The value is the calibrated, explainable probabilities and the replay, not a claim to beat simple models.

Cricket · VR and hardware

SwingLab

SwingLab turns a 3D-printed cricket bat held in a Meta Quest 3 controller into a batting trainer. It tracks every swing, scores it against a bowled ball and shows how consistent you are.

What you can do

  • Calibrate in a few seconds: it finds the bat's pivot point and your stance.
  • Play a drill of bowled balls. Each swing gets a contact result and a 0 to 100 rating.
  • Review every ball: swing speed, plane, path angle, backlift and timing, plus how repeatable your swings are.
  • Try it without a headset using the built-in practice simulator, which runs in any browser.

How it works

  • Tracking: WebXR and three.js read the controller pose every frame. The bat's pivot comes from a least-squares fit with outlier trimming.
  • Swing detection: swings are segmented by bat-tip speed with hysteresis, then measured for peak speed, plane tilt, path angle, backlift and timing.
  • Contact: a swept test between the moving blade and the ball decides the outcome from the face angle, so fast swings cannot tunnel through the ball.
  • Rating: 45% contact quality, 30% power and 25% control.
