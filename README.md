# Manish Modwani — Portfolio

Static, dependency-free portfolio site (HTML/CSS/JS). Deploys on GitHub Pages.

## Deploy
1. Create a public repo named `manimod7.github.io` on GitHub.
2. Push these files to the `main` branch.
3. Repo Settings → Pages → Source: "Deploy from a branch" → `main` / root.
4. Live at https://manimod7.github.io in about a minute.
